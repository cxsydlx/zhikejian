知课笺 · 交互动效预览

8 条元素级动效的真实运行演示。参数与工程 common/DesignToken.ets 的 Motion 类一一对应， 时长与曲线均取自 ArkUI 内置枚举，可直接照此落地。

下方动画均在自动循环播放 时长基准 150 / 300 / 350 / 400 / 450 ms 曲线基准 FastOutSlowIn · EaseOut · EaseIn · EaseInOut 目标平台 HarmonyOS · ArkTS
01

全局按压反馈

按下任意可点元素时该元素轻微内收，松开后回弹，给出「已接住」的触觉暗示。

触发按下 / 抬起
变化scale 1 → 0.96
时长150 ms
曲线FastOutSlowIn
真实鼠标按下也能触发 —— 把指针压上去试试
02

开始听课按钮

底色与图标同步切换，让「录音中」这个状态变化一眼可见，不靠读文字。

触发点击开始 / 停止
变化#0A59F7 → #C0492F
图标麦克风 → 方块
时长 / 曲线200 ms · FastOutSlowIn
开始听课 停止听课
点击按钮可手动切换，松手后自动继续循环
03

录音状态呼吸点

安静的页面里需要一个「活着」的信号。呼吸比闪烁更不打扰，也不会把视线带走。

触发录音进行中无限循环
变化scale 1 ↔ 1.25
光晕同步 1 → 2.25 倍
时长 / 曲线1200 ms · EaseInOut
正在听课 · 00:12
1200ms 一个来回，与真实语音的呼吸节奏接近
04

转写条目入场

新识别结果从下往上浮入。开场不能太长，否则连续说话时文字会追不上语音。

触发新转写结果到达
位移+12 vp → 0
不透明度0 → 1
时长 / 曲线300 ms · EaseOut
只保留最近 3 条，超出后最早的自动退出
05

选择器选中切换

设置页最频繁的交互。选中项要一眼可辨，但不要用位移 —— 位移会让整行跟着跳。

触发点击分段选择器
变化底色 + 字色过渡
位移无（避免行跳动）
时长 / 曲线150 ms · FastOutSlowIn

06

分区展开收起

高度动画必须配合同步的箭头旋转，否则用户既不知道是开还是关，也不知道这里能点。

触发点击分区标题行
高度0 ↔ 自适应
箭头rotate 0° → 180°
时长 / 曲线400 ms · FastOutSlowIn
语音识别
端侧引擎 — 鸿蒙端侧识别，零流量零加载
私有云 WSS — 流式返回，实时出字
大模型 API — 按停顿切段，兼容任意厂商
点击标题行可手动开合
07

周次横向切换

让「周」这个概念有方向感。整体位移比逐格刷新更容易让人理解刚才发生了什么。

触发左右滑动课表
位移± 全宽（跟手）
不透明度0.6 → 1
时长 / 曲线350 ms · EaseInOut
第 8 周 ⇄ 第 9 周，整轨平移而非重绘
08

视图布局切换

课表与列表是同一份数据的两种视角，用交叉淡化表达「换了个看法」而不是「翻页了」。

触发课表 / 列表互切
不透明度交叉淡化
缩放0.98 → 1
时长 / 曲线450 ms · FastOutSlowIn
理论力学 A · 二教 207
高等数学 B · 三教 105
大学物理 · 实验楼 302
两层叠加交叉淡化，位移为 0，只有轻微缩放

以上曲线全部为 ArkUI 内置 Curve 枚举成员；需要弹性时改用 @ohos.curves 的 springCurve() / springMotion()。

时长基准与该工程 Motion 类一致：触摸反馈 150ms / 列表增删 300ms / 页面转场 350ms / 面板展开 400ms / 布局切换 450ms。
